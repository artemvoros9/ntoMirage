# RADIATION SANDBOX — артбук и технический паспорт

## Концепция
Интерактивная 3D-песочница визуализирует распространение радиационных потоков в статичной лабораторной сцене. Игрок размещает источник, преграды, зеркала, магниты и дозиметры, наблюдая за изменением траекторий и накопленной дозы.

## Визуальный язык
- **Оранжевый** — активные частицы и источник.
- **Синий → жёлтый → красный** — градиент накопленной дозы дозиметра.
- **Циан** — выбранный объект и интерактивные элементы интерфейса.
- Тёмный фон лаборатории повышает контраст радиационного потока.

## Объекты
1. Источник: omni / cone / ray, скорость, интенсивность, lifetime и вариативность.
2. Частица: отдельный физический объект с кинематикой, SphereCast и индивидуальным временем жизни.
3. Opaque barrier: полностью блокирует поток.
4. Attenuating barrier: `T = exp(-μρL)`.
5. Mirror: отражает скорость по нормали поверхности.
6. Speed reducer: trigger-зона, уменьшающая скорость и интенсивность по длине пути.
7. Magnet: притягивает/отталкивает частицы силой, зависящей от расстояния.
8. Dosimeter field: настраиваемая сетка сфер с плавным цветовым откликом.
9. Critical object: при критической дозе активирует вторичный omni-источник.

## Сценарии демонстрации
- **Concrete attenuation**: конус последовательно проходит бетонные блоки разной толщины.
- **Mirror delivery**: луч отражается в закрытый контейнер; один из трёх магнитов искривляет траекторию.
- **Secondary emission**: графитовый стержень получает дозу в газовой зоне и становится локальным источником.

## Управление
Клик по объекту выбирает его и создаёт циановую рамку. Выбранный объект перетаскивается мышью по рабочей плоскости. Debug-панель показывает FPS, число активных частиц, количество коллайдеров, CPU-время кадра, скорость симуляции, паузу и перезапуск. Сцены переключаются кнопками сценариев.

## Техническая схема
`RadiationSource → RadiationParticle → SphereCast → IRadiationInteraction / IRadiationVolume → Dosimeter / Critical object`.
GPU instancing используется для визуализации частиц, а физическое состояние остаётся индивидуальным для каждого `RadiationParticle`.

## Арт-набор для защиты
Рекомендуемые кадры: общий вид лаборатории; источник и cone-flow; бетонные блоки с разной прозрачностью потока; mirror + magnets; close-up дозиметров; момент вторичной эмиссии; debug-панель с выбранным объектом.
