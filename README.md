# NTO Mirage — Radiation Simulation

Интерактивный Unity-проект для исследования распространения радиационных частиц, их ослабления, отражения, ускорения и накопления дозы.

## Возможности

- Источники частиц с настраиваемой скоростью, временем жизни, интенсивностью и формой потока.
- Омнидирекциональное излучение, конус и направленный луч.
- Ослабляющие и непрозрачные барьеры.
- Зеркала с отражением частиц и регулируемой отражающей способностью.
- Магниты, притягивающие или отталкивающие частицы.
- Объёмы замедления с потерей интенсивности.
- Дозиметры и автоматически создаваемые поля дозиметров.
- Критические объекты, активирующие вторичный источник после накопления заданной дозы.
- Runtime-панель для выбора объектов и изменения параметров без остановки сцены.
- Перемещение, вращение и изменение размера выбранных объектов.
- Управление камерой в стиле Blender.
- Четыре демонстрационных сценария.

## Требования

- Unity **6000.5.6f1**.
- Universal Render Pipeline 17.5.0.
- Input System 1.20.0.
- Windows или другая платформа, поддерживаемая используемой версией Unity.

## Запуск

1. Откройте проект через Unity Hub.
2. Откройте сцену `RadiationDemo`.
3. Нажмите Play.
4. Если в сцене нет контроллера, он создаётся автоматически после загрузки сцены.
5. Для переключения панели используйте `F1`.

## Управление

### Камера

- Средняя кнопка мыши + движение — вращение вокруг точки фокуса.
- `Shift` + средняя кнопка мыши + движение — панорамирование.
- Колесо мыши — приближение и отдаление.

### Объекты

- Левая кнопка мыши по объекту — выбрать объект.
- Зажатая левая кнопка мыши — перемещать выбранный объект по горизонтальной плоскости.
- Высота, поворот и размер изменяются в панели инспектора.
- Средняя кнопка мыши используется только для камеры.

## Демонстрационные сценарии

Сценарии выбираются в панели слева:

1. `RadiationDemo` — базовая сцена.
2. `Scenario_ConcreteAttenuation` — ослабление бетонными барьерами.
3. `Scenario_MirrorMagnet` — отражение и магнитное поле.
4. `Scenario_SecondaryEmission` — критический объект и вторичный источник.

## Основные компоненты

| Компонент | Назначение |
|---|---|
| `RadiationSource` | Создаёт и настраивает поток частиц |
| `RadiationParticle` | Движение, столкновения и интенсивность частицы |
| `AttenuatingRadiationBarrier` | Ослабляет или блокирует излучение |
| `RadiationMirror` | Отражает частицы |
| `RadiationMagnet` | Изменяет направление движения частиц |
| `RadiationSpeedReducer` | Замедляет частицы внутри trigger-объёма |
| `RadiationDosimeter` | Накопитель дозы |
| `RadiationDosimeterField` | Генерирует сетку дозиметров |
| `CriticalRadiationObject` | Активирует вторичный источник после достижения порога |
| `RadiationSandboxController` | UI, выбор объектов и управление камерой |

## Настройка источника

Добавьте `RadiationSource` на GameObject и назначьте prefab частицы. Prefab должен содержать:

- `RadiationParticle`;
- `Rigidbody`;
- `SphereCollider`;
- Renderer.

Параметры источника можно менять в Inspector Unity или в runtime-панели проекта.

## Настройка взаимодействий

Компоненты взаимодействия требуют Collider:

- Для барьера используйте обычный Collider.
- Для `RadiationSpeedReducer` используйте Collider с включённым `Is Trigger`.
- Для зеркала задайте `reflectivity` от 0 до 1.
- Для магнита задайте радиус, силу, falloff и полярность.

## Архитектура симуляции

Частицы создаются и переиспользуются источником через пул GameObject. На каждом физическом шаге частица рассчитывает движение, магнитное ускорение, SphereCast столкновений и прохождение через объёмы. Интенсивность уменьшается при удалении от источника и после взаимодействий. Визуальный размер частицы зависит от текущей интенсивности.

## Примечания

- Runtime-настройки действуют во время текущего запуска сцены.
- Частицы источника движутся в мировых координатах и не наследуют последующее перемещение источника.
- Некоторые ссылки на Unity-ассеты, например prefab и Material, удобнее назначать через обычный Inspector.
- Папки `Library` и `PackageCache` являются сгенерированными или сторонними данными и не требуют ручного редактирования.
